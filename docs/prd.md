# Product Doc

Goal: build a planning assistant for content plans.

## Loop

positioning -> reference review -> topic plan -> draft -> review -> data review -> next plan

## MVP

1. Positioning
2. Reference review
3. Topic plan
4. Drafting
5. Data review

## Module Outputs

- Positioning: reader, scene, problem, pillars, first plan
- Reference review: title pattern, cover pattern, body pattern, demand signal
- Topic plan: topic list with reader, scene, problem, outcome
- Drafting: title options, cover text, outline, draft, tags
- Data review: signal summary, bottleneck, next test
