# Methodology

## Core Loop

1. Define the reader.
2. Define the scene.
3. Define the problem.
4. Find reference examples.
5. Extract reusable patterns.
6. Create topic options.
7. Draft one piece.
8. Review quality.
9. Record metrics.
10. Plan the next piece.

## Positioning Formula

```text
For [reader], in [scene], solve [problem], with [content format], toward [business goal].
```

## Reference Review Fields

- reader
- scene
- problem
- title pattern
- cover pattern
- body pattern
- keywords
- comments
- reusable pattern

## Topic Formula

```text
reader + scene + problem + outcome
```

## Draft Formula

```text
pain empathy -> reason -> solution -> next action
```

## Data Review Principle

Metrics are signals, not final answers. Treat each result as one experiment.
