# Example: AI Tools Account

## Input

Niche: AI tools

Reader: office workers who want practical productivity gains

Offer: templates, small tools, learning notes, or a paid community later

Capacity: 5 posts per week

## Positioning

For office workers who want to use AI at work, share simple workflows, templates, and real use cases that can be tried in one day.

## Content Pillars

1. Beginner guides
2. Workflow examples
3. Tool comparisons
4. Prompt templates
5. Mistake reviews
6. Weekly tool notes

## Topic Examples

| Topic | Reader | Scene | Problem | Outcome |
|---|---|---|---|---|
| Use AI to write a weekly report | office worker | Friday report | no structure | finish faster |
| Use AI to summarize meeting notes | project member | after meeting | notes are messy | clear action list |
| 5 AI tools I still use | beginner | choosing tools | too many choices | simple shortlist |
| New users should not start from prompts | beginner | first week | learning path is wrong | start from scenes |

## Draft Structure

```text
pain empathy -> reason -> solution -> next action
```

## Review Focus

- Is the reader clear?
- Is the scene concrete?
- Is the result believable?
- Is the next action simple?
