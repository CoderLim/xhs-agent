# Reference Review Skill

## Purpose

Break down a high-performing reference post into reusable patterns.

## When to use

Use this skill when the user provides a reference title, screenshot, body text, account page, metrics, or comments.

## Inputs

- title
- cover text or cover description
- body text
- visible metrics
- comments
- account context

## Process

1. Identify the reader.
2. Identify the scene.
3. Identify the problem.
4. Identify the promised outcome.
5. Break down the title pattern.
6. Break down the cover pattern.
7. Break down the body structure.
8. Extract demand signals from comments.
9. Separate reusable patterns from parts that should not be copied.

## Output

```text
Worth reviewing:
Reader:
Scene:
Problem:
Outcome:
Title pattern:
Cover pattern:
Body pattern:
Keyword pattern:
Comment demand:
Reusable pattern:
Do-not-copy parts:
Adaptation ideas:
```

## Quality rules

- Learn structure, not content.
- Do not copy images, personal stories, or claims.
- Treat visible metrics as signals, not final proof.
- Prefer recent and niche-relevant references.
