# Topic Planning Methods

Use these methods when running `xhs-agent 选题`.

The source notes define a good topic as:

```text
一个具体的人，在一个具体场景里，遇到了一个具体问题，并想得到一个具体结果。
```

In this repository, use this formula:

```text
reader + scene + problem + outcome
```

## Topic Sources

Use these sources from the provided notes:

1. Reference notes
2. Comment questions
3. Search suggestion terms
4. Topic tags
5. Niche keywords
6. Reader keywords
7. Product or offer keywords
8. Pain-point keywords
9. Desire-point keywords
10. Tool or method keywords

## Topic Types

Generate a balanced list across these types:

- search topic: matches a clear search need
- collection topic: likely to be saved
- tutorial topic: teaches a method
- comparison topic: helps choose between options
- mistake topic: explains common traps
- real practice topic: based on real process
- conversion-related topic: connects to offer or product without hard selling

## Topic Quality Checklist

A topic is too broad if it sounds like:

```text
AI 工具推荐
英语学习方法
小红书运营技巧
```

Make it concrete:

```text
上班族每周写周报，怎么用 AI 整理出不空的版本
每天只有 10 分钟，怎么练到敢开口说英语
新手做账号，为什么不要一上来就发工具推荐
```

## Comment-to-Topic Method

When comments are available:

1. Extract repeated questions.
2. Extract requests for templates or resources.
3. Extract objections and confusion.
4. Convert each into a topic.

Example:

```text
Comment: 有没有适合职场的？
Topic: 职场人怎么用 AI 写一份不空洞的周报
```

## Search-Term Method

When search terms are available:

1. Keep terms with clear user intent.
2. Group them by reader, scene, problem, and outcome.
3. Use the term naturally in topic and title direction.

## Reference-to-Topic Method

When reference patterns are available:

1. Keep the same demand type.
2. Change the scene, case, and example.
3. Adapt it to the user's account positioning.

Do not reuse the original personal story.

## Output Quantity

Default output: 30 topics.

If the user asks for a smaller list, follow the user request.
