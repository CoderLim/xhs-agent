# Body Templates

Use these structures when writing the body of a note.

These templates come from the user's provided source notes. They are not magic formulas. Use them to make the note clearer and more useful.

## Core Body Structure

```text
pain empathy -> reason -> solution -> next action
```

In Chinese writing terms:

```text
痛点共情 -> 原因点破 -> 给出方案 -> 行动引导
```

## Template 1: Pain-Solution Note

Use for workplace, learning, tool use, parenting, travel, and other practical problems.

### Structure

1. Start with a concrete scene.
2. Describe the pain in plain language.
3. Explain why the old method does not work.
4. Give a simple solution.
5. Add a small example.
6. End with a clear next action or comment question.

### Skeleton

```text
你有没有遇到过这个场景：
[具体人群] 在 [具体场景] 里，想 [目标]，但总是 [痛点]。

问题不一定是你不会，而是 [原因点破]。

可以先这样做：
1. [步骤一]
2. [步骤二]
3. [步骤三]

举个例子：
[具体示例]

下次遇到 [场景]，先试试这个方法。
[评论问题]
```

## Template 2: Tutorial Note

Use when teaching a repeatable method.

### Structure

1. State the problem.
2. Tell the reader what they will get.
3. Give steps.
4. Add example or prompt.
5. Mention common mistakes.
6. End with save/comment prompt.

### Skeleton

```text
很多人做 [事情] 的时候，会直接 [常见错误]。

但如果你想要 [结果]，可以按这几步来：

第一步：[步骤]
为什么：[解释]

第二步：[步骤]
为什么：[解释]

第三步：[步骤]
为什么：[解释]

一个可以直接改的模板：
[模板]

注意：
[避坑提醒]

如果你也卡在 [问题]，可以先收藏，照着改一版。
```

## Template 3: Review / Comparison Note

Use for tool reviews, method comparisons, or choosing between options.

### Structure

1. Start from a real selection scene.
2. Explain why the choice is confusing.
3. Compare by scene, not by vague ranking.
4. Give recommendation by user type.
5. End with a decision rule.

### Skeleton

```text
最近很多人在纠结 [A] 和 [B]。

我不建议只看哪个更火，因为不同场景适合的东西不一样。

如果你是 [人群一]，更适合 [选择]，原因是 [原因]。

如果你是 [人群二]，更适合 [选择]，原因是 [原因]。

我的判断规则是：
先看 [场景]，再看 [成本]，最后看 [能否持续使用]。

你现在更常用在哪个场景？
```

## Template 4: Collection Note

Use for templates, tools, resources, book lists, routes, and checklists.

### Structure

1. Name the reader and scene.
2. Explain why this collection is useful.
3. Group items by use case.
4. Keep each item short.
5. End with how to use the list.

### Skeleton

```text
如果你是 [人群]，经常在 [场景] 卡住，可以先看这份清单。

我按使用场景分成了几类：

一、[类别一]
- [项目]：适合 [场景]
- [项目]：适合 [场景]

二、[类别二]
- [项目]：适合 [场景]
- [项目]：适合 [场景]

不要一次全用。
先选和你当前问题最接近的一个。

你最想要哪一类？我可以继续整理。
```

## Template 5: Real Practice Note

Use when the creator has a real process or experience to share.

### Structure

1. Start from a real scene.
2. Say what changed.
3. Explain the previous wrong method.
4. Share the new process.
5. Add conditions and limitations.
6. End with a practical suggestion.

### Skeleton

```text
我之前做 [事情] 的时候，最容易卡在 [问题]。

后来我发现，真正影响结果的不是 [表面原因]，而是 [核心原因]。

现在我会这样做：
1. [动作一]
2. [动作二]
3. [动作三]

这个方法适合 [适用人群]。
如果你是 [不适用情况]，可能要先 [前置条件]。

这不是万能方法，但能帮你先从 [卡点] 里出来。
```

## Writing Style Rules

- Use `你` instead of broad group words when possible.
- Use short paragraphs.
- Keep one paragraph within about two lines when possible.
- Avoid abstract claims without examples.
- Prefer scene language over concept language.
- Do not invent personal experience.
- If the experience is hypothetical, say it is a template or example.
