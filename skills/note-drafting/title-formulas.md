# Title Formulas

Use these formulas when running `xhs-agent 写笔记`.

These methods come from the source notes in this project. Treat them as writing heuristics, not guarantees.

## Title Principles

- Put the core reader, scene, pain point, or benefit as early as possible.
- Keep the title specific.
- Avoid stacking keywords without a readable sentence.
- The source notes mention keeping titles within about 20 Chinese characters when possible. Treat this as a useful reference, not a hard rule.
- The title must match the body.
- Do not promise fixed results.

## Formula 1: Reader + Pain + Solution

Use when the note solves a concrete problem.

```text
[reader] + [pain] + [solution]
```

Examples:

```text
职场人用 AI 写周报，别再只说帮我写一篇
新手用 AI 工具，先别急着买会员
```

## Formula 2: Pain Question + Missing Cause

Use when many users have tried but failed.

```text
[problem] 不好用？你可能少了 [key condition]
```

Examples:

```text
AI 写周报不好用？你可能少给了 4 类信息
AI 生成文案很空？先补这 3 个上下文
```

## Formula 3: Number + Method + Result

Use for tutorials, checklists, and templates.

```text
[number] + [steps/items] + [method] + [result]
```

Examples:

```text
3 步让 AI 帮你整理会议纪要
5 个提示词，让周报不再像流水账
```

## Formula 4: Identity + Scene + Change

Use for personal experience or real practice notes.

```text
[identity] + [scene] + [before/after change]
```

Examples:

```text
打工人写周报，我现在都用这个 AI 流程
前端开发做小工具，我先让 AI 做这 3 件事
```

## Formula 5: Misunderstanding + Correct View

Use when you want to break a common misconception.

```text
[common action]，最重要的不是 [surface thing]
```

Examples:

```text
用 AI 写周报，最重要的不是 Prompt
做 AI 工具号，别一上来就发工具推荐
```

## Formula 6: Collection / Save-worthy

Use for high-collection notes such as templates, tools, checklists, and resources.

```text
[number] + [useful items] + [clear audience/action]
```

Examples:

```text
10 个我每天都在用的 AI 提示词
打工人可以直接复制的周报模板
```

## Method: Title Hybrid

Use this when reference titles are available.

1. Collect 5-10 high-performing titles in the same niche.
2. Split each title into chunks: reader, scene, pain, result, emotional word, number.
3. Keep the reusable chunks.
4. Recombine them into new titles.
5. Replace the original case, story, and claim with the user's own topic.

Do not copy a full title if it is too close to the reference.

## Method: Three-step Title Method

1. Search or collect 5-10 reference titles.
2. Break them into modules.
3. Recombine modules into new titles.

The goal is to reuse the demand and structure, not the original content.

## Method: Positive / Negative Stimulus

The source notes describe positive and negative stimulus as a title method.

Positive direction:

```text
[method/product] + [low effort or short path] + [desirable result]
```

Negative direction:

```text
[not doing something] + [loss/regret] + [urgency]
```

Risk rule:

- Use negative titles only for real mistakes, risks, or avoidable traps.
- Do not create fear for attention.
- Do not exaggerate loss.
- Do not use false urgency.
