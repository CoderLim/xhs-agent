# Note Drafting Skill

## Purpose

Turn one selected idea into a complete post draft.

## Inputs

- idea
- reader
- scene
- problem
- result
- account positioning
- reference pattern
- constraints

## Steps

1. Create title options.
2. Create cover text options.
3. Create an outline.
4. Write the draft.
5. Add tags.
6. Add a comment question.
7. Review clarity and trust.

## Draft structure

```text
pain -> reason -> solution -> next action
```

## Output

```text
Title options:
Cover text options:
Outline:
Draft:
Tags:
Comment question:
Review notes:
```

## Rules

- Use short paragraphs.
- Make the scene concrete.
- Keep the solution easy to try.
- Do not invent personal experience.
