# Writing Principles

Use these principles before and after drafting.

They come from the user's writing framework: value, structure, and reader sense.

## 1. Value Sense

A note can provide three levels of value:

```text
WHAT: what it is
WHY: why it matters
HOW: how to do it
```

Priority:

```text
HOW > WHY > WHAT
```

A useful note should not only explain a concept. It should help the reader do something.

Before drafting, decide:

```text
This note helps the reader understand WHAT:
This note helps the reader understand WHY:
This note helps the reader do HOW:
```

If the HOW part is weak, strengthen it with:

- steps
- checklist
- template
- example
- decision rule
- common mistakes

## 2. Structure Sense

Do not only express what the creator wants to say. Design the reading path.

Use this five-part structure when suitable:

```text
场景导入 -> 打破认知 -> 核心逻辑 -> 举一反三 -> 回顾总结
```

Meaning:

1. 场景导入: start from a scene close to the reader.
2. 打破认知: point out a surprising or easily ignored view.
3. 核心逻辑: explain the core method with examples.
4. 举一反三: extend to similar scenes or HOW steps.
5. 回顾总结: summarize the key points.

This structure can be combined with the note body template:

```text
痛点共情 -> 原因点破 -> 给出方案 -> 行动引导
```

## 3. Reader Sense

Write as if speaking to one concrete reader.

Rules:

- Use `你` when possible.
- Avoid vague group language.
- Use concrete scenes.
- Use short, natural sentences.
- Do not write as if facing a blank document.
- Imagine the reader asking: `这和我有什么关系？我下一步能做什么？`

## Final Check

Before returning a draft, check:

```text
Value: Does the reader get a clear HOW?
Structure: Is there a smooth reading path?
Reader: Does it feel like speaking to one person?
```
