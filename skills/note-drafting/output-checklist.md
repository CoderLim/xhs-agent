# Output Checklist

Use this checklist before returning a note draft.

## Required Output

Every `xhs-agent 写笔记` result must include:

```text
1. Reader / Scene / Problem / Outcome
2. 10 title options
3. Recommended title and reason
4. 3 cover text options
5. Recommended cover and reason
6. Body structure
7. Full draft
8. Tags / keywords
9. Comment question
10. Risk notes
```

## Reader / Scene / Problem / Outcome

Before writing, make the basic unit clear:

```text
Reader:
Scene:
Problem:
Outcome:
```

If any of these is missing, ask one question or infer cautiously from memory.

## Title Check

A good title should answer at least one of these:

- Who is this for?
- What scene is this about?
- What pain does it solve?
- What result can the reader expect?
- Why should the reader click now?

Do not use a title if:

- it does not match the body
- it promises a fixed result
- it uses unsupported numbers
- it only stacks keywords
- it sounds like a claim the creator cannot support

## Cover Check

A good cover should have:

- one main message
- one supporting message
- clear relation to the title
- simple visual direction

Do not use cover text that creates a different promise from the body.

## Body Check

The body should:

- open with a concrete scene
- point out the real reason
- give a simple method
- include an example or template
- end with a clear next action

## Comment Question Check

The comment question should invite real user demand.

Good types:

- ask which scene the reader wants next
- ask which problem they are stuck on
- ask which option they are choosing between

Avoid empty questions such as `你觉得呢？`.
