# Cover Patterns

Use these rules when creating cover text.

## Core Principles

- Main message first.
- Supporting message second.
- Decorative message last.
- The source notes mention that cover text should not take too much space. Use this as a reference.
- The cover must match the title and body.
- Learn the structure of references, but use original wording and original material.

## Pattern 1: Pain Cover

Use when the note solves a painful scene.

```text
[scene or pain]？
[missing reason or solution]
```

Examples:

```text
周报写不出来？
少给了 4 类信息
```

```text
内容写得很空？
先补上下文
```

## Pattern 2: Result Cover

Use when the note gives a clear outcome.

```text
[method]
[clear result]
```

Examples:

```text
AI 写周报
减少空话
```

```text
会议纪要
整理成行动项
```

## Pattern 3: Comparison Cover

Use when explaining a mistaken approach and a better approach.

```text
普通做法
vs
更好做法
```

Examples:

```text
直接让 AI 写
vs
先给 4 类信息
```

```text
工具推荐
vs
场景工作流
```

## Pattern 4: Collection Cover

Use for templates, checklists, tools, and resource notes.

```text
[number] 个 [useful things]
[reader or action]
```

Examples:

```text
10 个 AI 提示词
职场人常用
```

```text
周报模板
照着改就行
```

## Pattern 5: Scene Cover

Use when the note is tied to a concrete daily scene.

```text
[reader] 的 [scene]
[one-line solution]
```

Examples:

```text
打工人周五
这样写周报
```

```text
开会后 10 分钟
整理出行动项
```

## Output Requirement

For each note, output 3 cover text options:

1. pain cover
2. result or comparison cover
3. collection or scene cover

For each option, include:

```text
Main text:
Supporting text:
Visual idea:
Why it fits:
```
