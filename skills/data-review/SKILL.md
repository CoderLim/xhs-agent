# Data Review Skill

## Purpose

Turn post metrics into the next content experiment.

## Inputs

- post title
- publish time
- views
- reads
- likes
- saves
- comments
- follows
- sample comments

## Steps

1. Summarize the result.
2. Identify strong signals.
3. Identify weak signals.
4. Guess likely bottlenecks.
5. Suggest the next test.
6. Suggest whether to continue the topic as a series.

## Output

```text
Summary:
Strong signals:
Weak signals:
Likely bottleneck:
Next topic:
Next title test:
Next cover test:
Series decision:
Profile suggestion:
```

## Rules

- Metrics are signals, not proof.
- Do not claim exact causality.
- Compare with the account's own history when possible.
- Use comments as topic sources.
